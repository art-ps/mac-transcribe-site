# Установка

## Скачать и перенести

Скачайте DMG с [лендинга](https://art-ps.github.io/mac-transcribe-site/), откройте его и перетащите MacTranscribe в папку «Программы». После этого запустите приложение оттуда.

## Первый запуск

При первом запуске открывается окно знакомства. Оно показывается при каждом запуске, пока вы не дойдёте до кнопки «Готово» на последнем шаге; если закрыть окно крестиком, оно появится снова при следующем запуске. Шагов шесть: приветствие, разрешения, выбор моделей и три слайда о том, как пользоваться приложением («Как получить текст», «Несколько записей сразу», «Транскрипты — в ваши заметки»).

Вернуться к знакомству можно в любой момент: «Справка» → «Показать знакомство».

### Разрешения

На шаге «Два разрешения для записи» MacTranscribe просит два разрешения, у каждого своя кнопка «Разрешить».

**Микрофон** — нужен, чтобы записывать вашу речь. Система покажет текст «Запись микрофона для транскрипции разговора.»

**Запись экрана** — так через ScreenCaptureKit macOS отдаёт системный звук (то, что говорят собеседники в звонке); само видео экрана при этом не записывается.

Статус обновляется сам, как только вы выдали разрешение в «Системные настройки» → «Конфиденциальность и безопасность». Если системный диалог не появился, откройте нужный раздел там и включите MacTranscribe вручную.

Шаг можно пройти, ничего не выдав: тогда приложение попросит недостающее, когда вы в первый раз нажмёте «Запись», а без обоих разрешений запись не начнётся.

### Модели

На шаге «Какие модели скачать» вы выбираете, что скачать. Само приложение ничего не качает, пока вы не нажмёте кнопку.

| Модель | Размер | Что это |
| --- | --- | --- |
| Whisper Large | 947 МБ | самая точная из Whisper, любой язык; нужен Mac с памятью больше 8 ГБ |
| Whisper Turbo | 626 МБ | быстрее Large, точность чуть ниже; ею же приложение расшифровывает речь прямо во время звонка (live) |
| Whisper Small | 483 МБ | самая лёгкая, для Mac с 8 ГБ памяти, точность заметно ниже |
| GigaAM v3 | 326 МБ | «только русский»; на русской речи быстрее и точнее Whisper |
| Разделение говорящих | 36 МБ | «Две небольшие модели, чтобы в расшифровке было видно, кто говорит» |

Галки заранее стоят на трёх пунктах: Whisper, подходящий вашему Mac (Large при памяти больше 8 ГБ, иначе Small, с меткой «подходит вашему Mac»), GigaAM и «Разделение говорящих». Уже скачанное отмечено галкой и в выбор не попадает. На кнопке написан общий объём выбранного: «Скачать выбранные · <размер>».

После нажатия модели скачиваются по очереди, в порядке списка. Можно перейти к следующим шагам: загрузка продолжится, а закрытие окна её не прервёт. Рядом с каждой моделью виден статус: процент, «в очереди» или «ошибка» с кнопкой «Повторить». Кнопка «Отменить» снимает очередь, уже скачанное остаётся.

Настройки подстраиваются под скачанное, если вы раньше сами их не меняли. Для финального прохода берётся самая точная из скачанных Whisper, для live — Turbo, а если его нет, та же самая точная. Если скачан только GigaAM, он выбирается движком.

Интернет нужен только на время загрузки; дальше распознавание работает офлайн.

#### Если пропустить

«Пропустить» доступно, пока вы не нажали «Скачать выбранные». Запись при этом работает, но кнопка «Транскрибировать» остаётся недоступной, пока вы не скачаете хотя бы одну модель на вкладке [«Настройки» → «Модели»](/settings#модели). Задержав курсор над недоступной кнопкой, увидите подсказку, чего не хватает. Другие причины блокировки кнопки — в разделе [«Решение проблем»](/troubleshooting).

## Удаление

1. Выйдите из MacTranscribe.
2. Удалите `MacTranscribe.app` из папки «Программы».
3. Удалите оставшиеся на диске данные и выданные разрешения:

```bash
defaults delete in.pisarev.mac-transcribe

rm -rf ~/Library/Application\ Support/mac-transcribe
rm -rf ~/Library/Application\ Support/sherpa

# сбросить разрешения на микрофон и запись экрана
tccutil reset Microphone in.pisarev.mac-transcribe
tccutil reset ScreenCapture in.pisarev.mac-transcribe
```

Дальше — как связать записи с хранилищем и агентом: [«Встречи → хранилище → агент»](/workflow).
