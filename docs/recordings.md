# Работа с записями

## Где хранятся записи

Каждая запись — отдельная папка в `~/Library/Application Support/mac-transcribe/conversations`, внутри аудио и транскрипт.

Аудио пишется сразу в аудиокодек Opus, в контейнере `.ogg`.

## Прослушивание

Клик по фразе в транскрипте перематывает аудио на её начало. Фраза, которая играет сейчас, подсвечивается.

Кнопка «Скачать» сохраняет аудио отдельным файлом `.ogg` — через системное окно сохранения.

## Перетранскрибировать

Кнопка «Перетранскрибировать» открывает меню со скачанными моделями обоих движков — Whisper и GigaAM. Подробнее о движках и моделях — на странице [«Запись и транскрипция»](/transcription).

В том же меню есть галка «Разделить собеседников»: она запускает отдельный проход с разделением по спикерам, это не поведение по умолчанию.

## Поиск в списке

Поле «Поиск» стоит над списком записей. Оно ищет по названию и по тексту транскрипта: в списке остаются только подходящие записи, а под каждой показан фрагмент вокруг первого совпадения.

Регистр не важен, но «ё» и «е» считаются разными буквами. Идущая запись ищется только по названию — её транскрипта на диске ещё нет.

## Поиск в транскрипте

«Найти…» в меню «Правка» или ⌘F открывает строку с полем «Найти в транскрипте». Рядом счётчик: «N из M», а если совпадений нет — «Не найдено».

- Enter — следующее совпадение, Shift+Enter — предыдущее;
- Esc или крестик закрывает строку.

Поиск работает, когда открыта запись с транскриптом. На экране идущей записи и при выделении нескольких записей пункт недоступен.

## Просмотр во время записи

Пока идёт запись, старые записи можно открывать, слушать и читать. Экран записи возвращается, когда в списке выбрана строка идущей записи (её видно по пульсу) или снят выбор.

## Удалить аудио

Контекстное меню записи → «Удалить аудио». Для выделения нескольких записей пункт называется «Удалить аудио: N». Перед удалением приложение спрашивает: «Удалить аудио? Транскрипт останется, перетранскрибировать будет нельзя.»

Пункт доступен, только если у записи есть транскрипт, файл аудио на месте, а сама запись не пишется, не транскрибируется и не стоит в очереди. В выделении удаляются только подходящие записи.

После удаления у записи в списке значок «Аудио удалено», а вместо плеера внизу — та же надпись. Транскрипт можно читать и экспортировать.

## Удаление записи

«Удалить» в контекстном меню записи стирает её целиком. Приложение спрашивает: «Удалить разговор? Аудио и транскрипт будут стёрты безвозвратно.» Идущую запись удалить нельзя.

## Импорт готовых файлов

Импортировать можно аудио или видео файл — перетащить его в окно приложения или выбрать через меню «+» → «Импортировать аудио/видео файл». За один раз — только один файл.

После импорта файл перекодируется в тот же формат, что и запись — аудиокодек Opus в `.ogg`. Первый проход по импортированной записи идёт без разделения по спикерам.

## Несколько записей сразу

Выделить несколько записей в списке можно ⇧ Shift или ⌘ Cmd — так же, как в любом нативном списке macOS.

Над выделением работают четыре действия:

- «В хранилище: N» — экспортирует по очереди все выбранные записи, у которых уже есть транскрипт;
- «Транскрибировать: N» — ставит подходящие записи в очередь проходов;
- «Удалить аудио: N» — стирает аудио только у подходящих записей, транскрипты остаются; условия — в разделе [«Удалить аудио»](#удалить-аудио);
- «Удалить: N» — удаляет выбранные записи, кроме тех, что сейчас пишутся, транскрибируются или ждут своей очереди на транскрибацию.

## Экспорт

Транскрипт текущей записи экспортируется в TXT, Markdown или SRT — формат выбирается расширением файла в системном окне сохранения.

Кнопка «В хранилище» пишет markdown-файл с полным транскриптом в папку хранилища — обычную папку, хранилище Obsidian или папку проекта. По умолчанию файл уходит в ту же папку, где лежат записи, пока в [«Настройках»](/settings) не выбрана отдельная папка хранилища; сменить папку можно там же кнопкой «Выбрать папку…».

Имя файла — `MT-ГГГГ-ММ-ДД-ЧЧММ Название.md`.
