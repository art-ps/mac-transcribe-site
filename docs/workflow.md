# Встречи → хранилище → агент

Процесс держится на трёх участниках, и у каждого своя роль:

- **MacTranscribe** записывает разговор и расшифровывает его на вашем Mac, а кнопкой «В хранилище» кладёт транскрипт markdown-файлом в выбранную папку.
- **Хранилище** — обычная папка с файлами: набор из лендинга, существующий проект или хранилище Obsidian.
- **Агент** — Claude Code или Codex: вы запускаете его в этой папке, и он по промпту из `_prompts/` разбирает транскрипт и пишет результат в ту же папку.

Экспорт — кнопкой «В хранилище» в меню разговора; автоматического экспорта нет. Агента тоже запускаете вы.

Стартовый набор: [mactranscribe-starter-kit.zip](https://github.com/art-ps/mac-transcribe-releases/releases/download/starter-kit/mactranscribe-starter-kit.zip). Описание набора — на [лендинге](https://art-ps.github.io/mac-transcribe-site/).

## Маршрут 1: начинаю с нуля

1. Скачайте и распакуйте набор.
2. В MacTranscribe откройте Настройки → Основное → Хранилище → «Выбрать папку…» и выберите папку `Встречи` внутри набора. Подробнее о настройке — на странице [«Настройки»](/settings#основное). Если MacTranscribe ещё не установлен — страница [«Установка»](/install).
3. Запишите разговор, нажмите «Транскрибировать», затем «В хранилище».
4. В терминале перейдите (`cd`) в папку набора и запустите `claude` или `codex`. Вставьте текст промпта из `_prompts/` и строку `Файл: …` с транскриптом, который нужно разобрать.

## Маршрут 2: уже есть база знаний

1. Укажите в MacTranscribe папку внутри существующего проекта или хранилища Obsidian — например, `Встречи/` или `50 Raw/MacTranscribe/`.
2. Положите рядом `AGENTS.md` и `_prompts/` из набора. Claude Code читает `CLAUDE.md` с одной строкой `@AGENTS.md`, Codex — сам `AGENTS.md`.
3. Запускайте агента из корня этой папки — дальше всё как в первом маршруте, с шага 3.

## Claude Code

- Запускайте `claude` в папке набора или в корне своей базы знаний.
- Инструкции агент берёт из `CLAUDE.md`, где стоит `@AGENTS.md`, — так оба агента работают по одному файлу.
- Чтобы агент записал результат, нужно разрешение на правку файлов: подтверждайте каждую правку в чате или запустите `claude --permission-mode acceptEdits`. В режиме `--permission-mode acceptEdits` агент не запускает shell-команды, поэтому уже существующий разбор находит только по имени файла, а не по `source_id`.

## Codex

- Запускайте `codex` в папке набора или в корне своей базы знаний.
- Инструкции агент берёт из `AGENTS.md`.
- Чтобы агент мог писать файлы в этой папке, нужна песочница `workspace-write`.

## Чем проверено

- Claude Code 2.1.309 — все три сценария набора.
- Codex 0.153.4 — разбор интервью.

Оба агента работают по вашей собственной подписке или API-ключу.

## Как проверить цитату

У каждой реплики в транскрипте есть таймкод: `**[ЧЧ:ММ:СС] Имя:** текст`. Агент ссылается на него в строке `Источник:`. Откройте запись в MacTranscribe и кликните по реплике с этим таймкодом — плеер перемотает к этому месту, и фразу можно переслушать.

Если расшифровка неточная, запись можно перетранскрибировать другой моделью или с разделением по спикерам — подробнее на странице [«Работа с записями»](/recordings).

## Где лежат файлы

Записи — обычные файлы в Application Support, подробнее на странице [«Работа с записями»](/recordings).

Транскрипты, выгруженные кнопкой «В хранилище», лежат в выбранной папке хранилища; пока папка не выбрана — в папке записей. Имя файла — `MT-ГГГГ-ММ-ДД-ЧЧММ Название.md`. В начале файла — frontmatter с полями `type: raw`, `source: mac-transcribe`, `source_id`, `title`, `date`, `time`, `duration`, `speakers`, `tags`, дальше — реплики.
