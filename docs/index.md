# MacTranscribe

MacTranscribe записывает микрофон и системный звук встречи и превращает запись в текст. Всё происходит локально, на самом Mac.

## С чего начать

1. [Установка](/install)
2. [Запись и транскрипция](/transcription)
3. [Работа с записями](/recordings)
4. [Настройки](/settings)

## Требования

| Что | Значение |
| --- | --- |
| Система | macOS 26.4 и новее |
| Процессор | Apple Silicon |
| Место на диске | DMG ~60 МБ; модель распознавания речи — 483–947 МБ в зависимости от памяти Mac, скачивается при первом запуске |
| Разрешения | микрофон, запись экрана |

## Что MacTranscribe не делает

- не отправляет звук и транскрипты в сеть — подробнее на странице [«Приватность»](/privacy)
- не пишет видео
- не требует регистрации и подписки
