# Лендинг: строка «Для продактов…» на первом экране — дизайн

## Зачем

После редизайна строка «Для продактов: интервью, созвоны с командой, демо» стоит в «Сценариях», и с первого экрана не видно, для кого продукт (замечание финального ревью). Владелец: «сделай на первом экране».

## Что делаем

- Строку переносим (не дублируем): из `src/sections/Scenarios.tsx` убрать, в `src/sections/Hero.tsx` поставить сразу после абзаца `.lead` «MacTranscribe записывает и расшифровывает созвоны локально на Mac.», до кнопок.
- Разметка: `<p className="lead">Для продактов: интервью, созвоны с командой, демо</p>`; текст дословно.
- Стиль: тот же, что у первого `.lead` (цвет `--color-muted`), отступ между двумя абзацами `var(--space-xs)`: `.hero .lead + .lead { margin-top: var(--space-xs); }`.
- Не eyebrow (gate 67): строка ниже заголовка, обычный регистр, шрифт текста.

## Тесты

1. «hero names the audience»: `src/sections/Hero.tsx` содержит «Для продактов: интервью, созвоны с командой, демо», `src/sections/Scenarios.tsx` — нет.
