# Раздел документации на сайте MacTranscribe

Дата: 2026-09-26. Статус: дизайн утверждён в брейншторме. Образец — раздел документации
LangFlip (`~/projects/langflip-site/docs`, коммит `2eeeefb`).

## Зачем

У MacTranscribe есть только одностраничный лендинг. Пользователю негде прочитать, как
выдать разрешения, чем Whisper отличается от GigaAM, где лежат записи и что приложение
отправляет в сеть. Раздел документации закрывает это так же, как у LangFlip.

## Устройство

- **Движок:** VitePress `^1.6.4` — dev-зависимость сайта, как в LangFlip.
- **Исходники:** `docs/*.md` в репозитории сайта, конфиг `docs/.vitepress/config.mts`.
- **Сборка:** `npm run build` = нынешняя сборка лендинга `&& vitepress build docs`.
  VitePress пишет в `dist/docs`, один деплой GitHub Pages публикует лендинг и документацию.
  Добавляется скрипт `docs:dev` = `vitepress dev docs`.
- **Конфиг:**
  - `base: "/mac-transcribe-site/docs/"` — сайт живёт на подпути github.io, а не на своём
    домене, как LangFlip; ссылки из документации на лендинг — полным URL
    `https://art-ps.github.io/mac-transcribe-site/`;
  - `outDir: "../dist/docs"`, `lang: "ru-RU"`, `cleanUrls: true`, `lastUpdated: true`;
  - `srcExclude: ["superpowers/**"]` — рабочие спеки и планы не публикуются;
  - локальный поиск с русскими подписями, русские подписи навигации
    («На этой странице», «Назад»/«Дальше», «Обновлено» и т.д.) — как в LangFlip;
  - логотип и favicon — иконка приложения из `public/`;
  - nav: «Документация» → `/`, «Скачать» → лендинг;
  - footer: «Локальная транскрипция встреч для macOS. Проект vibecoded.ru» со ссылкой.
- **Аналитика:** umami с тем же `data-website-id`, что у лендинга, подключается с
  **`async`**, не `defer`: defer-скрипт выполняется в порядке документа и задерживает
  всё, что после него (см. коммит лендинга `d38df8f`).
- **Сайдбар** вынесен в `docs/sidebar.mjs` и импортируется конфигом — чтобы тест мог
  прочитать его без TypeScript.
- **Лендинг:** ссылка «Документация» (`./docs/`) в навигации шапки и в подвале
  `src/App.tsx`.

## Правила содержания

- **Каждое утверждение сверяется с кодом приложения** (`~/projects/mac-transcribe`,
  `master` на `93296fd`). Исполнитель в отчёте о задаче перечисляет, из каких
  `файл:строка` взят каждый факт страницы. Факт, не найденный в коде, на страницу не
  попадает.
- Опорные факты, уже проверенные при брейншторме:
  - автотранскрипция после остановки (`autoTranscribe`) и live (`liveTranscription`)
    по умолчанию выключены — `Sources/AppSettings.swift:132-133`;
  - проверка обновлений по умолчанию **включена** (`updateCheckEnabled`, `:138`),
    ходит в `api.github.com` за последним релизом `art-ps/mac-transcribe-releases`
    (`Sources/UpdateCheck.swift:86-87`), выключается в About;
  - проход после записи и после импорта идёт с `speakers: false`; разделение по спикерам —
    галка в меню «Перетранскрибировать» (`Sources/MacTranscribeApp.swift:394-395, 836, 1017`);
  - импорт принимает `.audio` и `.movie`, по одному файлу (`:201-209`);
  - записи — `~/Library/Application Support/mac-transcribe/conversations`
    (`Sources/ConversationStore.swift:12-14`); модели sherpa — `…/sherpa`;
  - модель Whisper по умолчанию — `small` (483 МБ) на Mac с ≤ 8 ГБ памяти, иначе
    `large-v3-turbo` (626 МБ); ещё `large-v3` (947 МБ) — `Sources/WhisperModels.swift:26-40`;
  - GigaAM работает только для русского и только если модель скачана, иначе проход
    уходит на Whisper — `Sources/EngineChoice.swift:18-25`;
  - вкладки настроек — `Sources/SettingsView.swift:15-26`.
- **Не упоминаются:** суммаризация и Claude (будут удалены из приложения), нотаризация
  Apple.
- **Opus** всегда пишется как «аудиокодек Opus» — чтобы не путать с моделью Claude Opus.
- **Приватность без обещаний сверх проверяемого:** у MacTranscribe нет CI-гейта
  приватности, как `verify-privacy.sh` в LangFlip, поэтому формулировок вида «это
  проверяется автоматически» нет.
- **Скриншотов нет.** Интерфейс описывается текстом и таблицами. Скриншоты добавятся
  вместе с пересъёмкой лендинга на демо-разговоре.
- Язык — русский; названия пунктов интерфейса — как в русской локализации приложения,
  в «ёлочках».

## Известное расхождение

Пока в приложении есть кнопка суммаризации, которая отправляет транскрипт в Claude,
страница приватности формально неполна. Это осознанное решение владельца: суммаризация
будет удалена из приложения, на сайте её уже нет.

## Приёмка — список проверок

1. `npm test` зелёный: старые тесты лендинга и новый тест сайдбара — каждый
   `docs/*.md` вне `superpowers/` есть в `docs/sidebar.mjs`, и каждый пункт сайдбара
   указывает на существующий файл.
2. `npm run build` создаёт `dist/docs/` с семью страницами (`index.html`, `install.html`,
   `transcription.html`, `recordings.html`, `settings.html`, `privacy.html`,
   `troubleshooting.html`) и не публикует ничего из `superpowers/`.
3. grep по `dist/docs`: нет «суммариз», «нотариз», «Claude»; каждое «Opus» стоит рядом
   со словом «кодек»; скрипт аналитики подключён с `async`.
4. На лендинге ссылка «Документация» в шапке и подвале ведёт на `./docs/`.
5. После деплоя: все семь страниц и ссылка с лендинга отвечают 200; в браузере открывается
   раздел, работает поиск и переход между страницами; нет горизонтальной прокрутки на
   ширине 390 px.

## Вне рамок

- Английская версия документации.
- sitemap.xml, llms.txt, JSON-LD, свой домен.
- CI-гейт приватности.
- Любые изменения в самом приложении.
