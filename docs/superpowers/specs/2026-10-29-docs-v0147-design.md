# Документация под MacTranscribe v0.1.47 — дизайн

## Зачем

Документация (`docs/*.md`, VitePress) написана 2026-10-01. В релизах 20–23 октября приложение получило окно знакомства, выбор моделей при первом запуске, поиск, удаление аудио и необязательную загрузку моделей разделения говорящих. Страницы молчат о новом, а часть старых утверждений стала неверной. Читатель, сверяющий доку с приложением, видит расхождения и перестаёт ей верить.

Владелец сказал «обнови», вопросы пропустил. Решения ниже — мои, помечены «(моё)».

## Источник истины

Код приложения `~/projects/mac-transcribe/Sources` на коммите `3365c38` — это `master`, из которого 2026-10-23 собран релиз v0.1.47. Каждое утверждение страницы сверяется с кодом, не с памятью и не с этой спекой: цитаты интерфейса копируются из строк `settings.text("…")` дословно (русский вариант). Расхождение спеки с кодом решается в пользу кода, с пометкой в отчёте.

Никогда не читать `~/Library/Application Support/mac-transcribe/` — там реальные разговоры владельца.

## Что меняется (по страницам)

Факты ниже я снял с кода; исполнитель перепроверяет каждый перед записью.

### `install.md` — «Первый запуск» переписать

Сейчас: «при первом запуске скачивает модель… и модели для разделения», разрешения спрашиваются по первой «Записи». Неверно.

Стало (`OnboardingView.swift`, `OnboardingLogic.swift`, `DependencyManager.swift`):
- При первом запуске открывается окно знакомства, пока оно не пройдено до конца (флаг завершения). Шаги: приветствие → «Два разрешения для записи» (кнопки «Разрешить» для микрофона и записи экрана) → «Какие модели скачать» → слайды «Как получить текст», «Несколько записей сразу», «Транскрипты — в ваши заметки».
- Экран моделей: список Whisper Large, Whisper Turbo, Whisper Small, GigaAM v3 («только русский»), «Разделение говорящих» («Две небольшие модели, чтобы в расшифровке было видно, кто говорит»). Галки по умолчанию: подходящая Mac модель Whisper (Large при памяти больше 8 ГБ, иначе Small, с меткой «подходит вашему Mac»), GigaAM и разделение говорящих — кроме уже скачанного. Кнопка «Скачать выбранные · <размер>»; загрузка идёт в очереди и продолжается, если перейти дальше.
- «Пропустить»: запись работает, но «Транскрибировать» недоступна, пока не скачана хотя бы одна модель в «Настройки → Модели».
- Открыть знакомство снова: «Справка → Показать знакомство».
- Абзац про GigaAM («не входит в этот набор») убрать или переписать: GigaAM теперь в наборе по умолчанию.
- Раздел «Разрешения» согласовать: просьба теперь приходит из знакомства (кнопки «Разрешить»), а если её пропустили — при первой «Записи» (проверить в коде).

### `recordings.md`

Добавить:
- **Поиск в списке** (`SidebarView.swift`, `TranscriptSearch.swift`): поле «Поиск» над списком; находит записи по названию и по тексту транскрипта, без учёта регистра, но «ё» и «е» различаются; под записью показан фрагмент вокруг первого совпадения.
- **Поиск в транскрипте** (`MacTranscribeApp.swift`, `TranscriptView.swift`): «Найти…», ⌘F; поле «Найти в транскрипте», счётчик «N из M» / «Не найдено», Enter — следующее, Shift+Enter — предыдущее, Esc закрывает. Недоступен на экране идущей записи и при выделении нескольких записей.
- **Просмотр во время записи**: пока идёт запись, можно открыть и читать старые записи; экран записи возвращается выбором текущей записи (проверить в коде, как именно).
- **Удалить аудио** (`SidebarView.swift`, `AudioDeletion.swift`, `MacTranscribeApp.swift`): в контекстном меню записи «Удалить аудио» (для выделения — «Удалить аудио: N»); подтверждение «Удалить аудио? Транскрипт останется, перетранскрибировать будет нельзя.» Доступно, только если есть транскрипт, файл аудио на месте и запись не пишется, не транскрибируется и не стоит в очереди.
- Удаление одной записи из контекстного меню («Удалить «Название»», подтверждение «Удалить разговор? Аудио и транскрипт будут стёрты безвозвратно.») — если в доке его нет, добавить рядом.

### `transcription.md`

- «Кто что сказал»: разделение собеседников требует скачанных моделей «Разделение говорящих» — они необязательные, ставятся в знакомстве или в «Настройки → Модели». Без них галка «Разделить собеседников» недоступна (проверить, как именно ведёт себя меню). Фразу «моделью, уже скачанной на диск» заменить.
- Таблица движков: проверить фразу «если модель не скачана или выбран не русский язык, проход всё равно идёт на Whisper» против `ModelGate.swift`/`OfflinePass.swift`: когда скачан только GigaAM, а язык не русский, транскрибация блокируется с сообщением, а не уходит на Whisper.
- Умолчания модели live/финального прохода проверить против `OnboardingModels.settingsAfterInstall`: после загрузки в знакомстве настройки ставятся под скачанное (лучшая Whisper для финального прохода; Turbo для live, только если скачана).

### `settings.md`

- Вкладка «Модели»: добавить раздел «Разделение говорящих» (одна строка, две модели, кнопки «Скачать»/«Отменить»). Сверить, что загрузки из знакомства видны здесь как идущие.
- Строку «Пока идёт одна загрузка, кнопки «Скачать» у остальных моделей недоступны» сверить с новой очередью загрузок (`DownloadQueue.swift`): возможно, теперь загрузки встают в очередь.
- Колонки «По умолчанию» для моделей сверить с правилами после знакомства.

### `troubleshooting.md`

- Строку «Кнопка «Транскрибировать» не реагирует» переписать по `ModelGate.swift`: причины и тексты подсказок — «Нет ни одной скачанной модели…», «GigaAM понимает только русский…», «Разделение говорящих требует две модели…». Упоминание «сегментация, голосовой эмбеддинг» как обязательных для финального прохода убрать, если код это подтверждает.
- Раздел «GigaAM выбран, а работает Whisper» согласовать с тем же гейтом.
- Строку «Модель не скачалась» сверить с очередью загрузок и строкой «ошибка»/«Повторить» в знакомстве.

### `index.md`, `privacy.md`

Проверить, не противоречат ли новому (размеры, «скачивается при первом запуске»). Править только найденное.

## Тесты (`tests/docs.test.mjs`)

Добавить проверки фактов, которые легко потерять при следующей правке:
1. В `install.md` есть «Показать знакомство» и «Пропустить».
2. В `recordings.md` есть «Удалить аудио», «⌘F» и «Найти в транскрипте».

4. Ни одна страница не утверждает, что модели скачиваются при первом запуске автоматически: нет фразы «При первом запуске MacTranscribe скачивает».

Существующие тесты не ослаблять.

## Ограничения

- Только `docs/*.md`, `docs/sidebar.mjs` (если появится страница) и `tests/docs.test.mjs`. Лендинг (`src/`) не трогать.
- Новые страницы не заводить (моё): всё ложится в существующие разделы. Знакомство — в «Установка», поиск и удаление аудио — в «Работа с записями».
- Скриншотов нет (моё): пересъёмка на демо-разговоре — отдельная задача бэклога.
- Нельзя: «суммаризация», «нотаризация», `xattr`, «В вольт», ссылки на приватные репозитории, цитаты исходников (`Sources/`, `.swift`) на страницах.
- Стиль страниц прежний: короткие абзацы, таблицы для пунктов настроек, цитаты интерфейса в «ёлочках».
- Проверки: `npm test`, `npm run lint`, `npm run build` зелёные.
- Пуш и деплой — только по «да» владельца.
